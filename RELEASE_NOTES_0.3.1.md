# OpenCifra v0.3.1 — Stability Hotfix

This maintenance update addresses an intermittent issue that could
cause OpenCifra to close unexpectedly on Android.

## Fixed

- Improved application stability to prevent occasional unexpected closures.

## Compatibility

- Android 7.0 (API 24) or newer.
- ARM 64-bit and ARM 32-bit devices.
- Updates existing OpenCifra v0.3 installations.
